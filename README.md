# Swingrapport

Publika dagliga rapporter från ett privat analysprogram för swingtrading: marknadsläge,
förslag att bedöma själv med beslutskort och motiveringar, samt månadens momentumlista.

**Sidan:** https://mansaaaav2.github.io/swingrapport/

> **Beslutsunderlag, inte investeringsrådgivning.** Inget här är en uppmaning att köpa eller
> sälja värdepapper. Förslagen tas fram automatiskt ur offentliga data och kan vara fel eller
> ofullständiga. Historisk avkastning och backtest garanterar inte framtida resultat.
> Ingen av signalerna har gett en överavkastning som klarat ett ärligt backtest.
> Gör alltid din egen bedömning.

Repot innehåller bara publikt material:

- inga positioner
- inget kapital eller andra kontouppgifter
- inga belopp i kronor som rör något konto
- inga hemligheter

Varje fil kontrolleras automatiskt före publicering, och publiceringen avbryts om något
otillåtet hittas.

Källor:

- kurser från Yahoo Finance
- insynshandel och blankning från Finansinspektionen
- pressmeddelanden från Cision (rubrik och länk)

Innehållet ersätts automatiskt. Repot består alltid av en enda commit, och arkivsidor
äldre än 180 dagar tas bort.
